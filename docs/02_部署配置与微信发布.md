## 2. 后端部署

建议使用 Python 3.11：

```bash
cd /opt/yeahpay/app
python3.11 -m venv venv
./venv/bin/pip install -r requirements-lock.txt
cp .env.example .env
```

`.env` 至少配置：

```dotenv
JWT_SECRET=<至少32位随机值>
ENVIRONMENT=production
CORS_ORIGINS=[]
DUCKDB_PATH=/opt/yeahpay/data/active/merchant.duckdb
DUCKDB_CANDIDATE_PATH=/opt/yeahpay/data/candidate/merchant.duckdb
DUCKDB_BACKUP_DIR=/opt/yeahpay/data/backup
SQLITE_PATH=/opt/yeahpay/app/data/biz.db
DUCKDB_RELEASE_GATE_ENABLED=true
ETL_SCRIPT_PATH=/opt/yeahpay/etl/cloud_etl.py
```

将交接包 `data/merchant.duckdb` 和 `data/ods_transactions_all-*.parquet` 一起复制到 `/opt/yeahpay/data/active/`。不要修改 Parquet 文件名，也不要只复制 DuckDB。候选目录同样必须一次放入这两个文件。

启动前验证：

```bash
JWT_SECRET=temporary-validation-secret-32bytes \
DUCKDB_PATH=/opt/yeahpay/data/active/merchant.duckdb \
SQLITE_PATH=/opt/yeahpay/app/data/biz.db \
PYTHONPATH=. ./venv/bin/python -m unittest discover -s tests -v
```

Uvicorn 建议只监听本机，由 Nginx 反代：

```ini
[Unit]
Description=YeahPay FastAPI
After=network.target

[Service]
User=ubuntu
WorkingDirectory=/opt/yeahpay/app
EnvironmentFile=/opt/yeahpay/app/.env
ExecStart=/opt/yeahpay/app/venv/bin/uvicorn main:app --host 127.0.0.1 --port 8000
Restart=always

[Install]
WantedBy=multi-user.target
```

## 3. Nginx 与 HTTPS

核心要求：

- `b-api.seeya.icu` 必须具备有效、完整链的 TLS 证书。
- `/api/` 转发到 `http://127.0.0.1:8000`。
- 保留 `Authorization` 请求头。
- 上传场景按需要设置 `client_max_body_size`，但正常小程序查询不上传 DuckDB。
- Cloudflare 若开启代理，TLS 模式应使用 Full (strict)。

部署后检查：

```bash
curl -fsS https://b-api.seeya.icu/health
curl -fsS https://b-api.seeya.icu/openapi.json
```

## 4. 微信开发者工具

1. 导入 `source/miniprogram`，项目类型选择“小程序”。
2. 使用有权限的正式 AppID，不要使用测试号上传。
3. 小程序不请求后端：`USE_REMOTE_API` 为 `false`。管理员在「上傳數據文件」页导入 JSON/CSV，看板从本机文件出数。
4. `project.private.config.json` 是个人 IDE 配置，交接包故意不包含。
5. 编译后先在模拟器登录，再执行“预览”真机扫码。
6. 上传代码时填写新版本号和说明。

## 5. 微信公众平台

在对应 AppID 的微信公众平台中：

- 开发管理 → 开发设置 → 服务器域名。
- 本小程序不发起 `wx.request`，不必把 `b-api.seeya.icu` 配进 `request` 合法域名。后端若仍独立提供 API，仅给其它客户端使用。
- 把内部演示人员加入开发者或体验成员。
- 在“版本管理”中将已上传版本设为体验版，体验成员扫该版本二维码。

“页面不存在”通常不是 API 域名问题，而是扫到了旧 A 版本、上传时选择了错误 AppID、启动页面路径不存在，或体验版仍指向上一上传版本。先核对 AppID、上传版本号和 `app.json.pages`。

## 6. 发布前不可省略的检查

- 模拟器、预览二维码、体验版三种环境均可登录。
- 开发者工具打开合法域名校验后，小程序仍可登录；数据来自本机上传文件，不请求远端 API。
- admin、supervisor、sales 三种角色分别回归。
- 管理员可切换全部/代理商/销售视角，非管理员不能越权。
- 正式和候选目录中的 `merchant.duckdb` 都能找到其同目录 `ods_transactions_all-*.parquet`。
- 微信后台不保存服务器密码；DNS 指向与 Nginx 反代决定 API 去向。
